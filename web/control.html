1连接阿里云

还没有配置。到阿里云百炼控制台创建以 sk- 开头的 API Key，粘贴到这里（不是模型名）。
国内默认 https://dashscope.aliyuncs.com；也可填工作空间专属地址。
默认 qwen-audio-3.0-asr-flash-streaming；也兼容 fun-asr-realtime。
指定后可减少语种误判；中英混说建议选自动。
说话停顿超过该时长就定稿一句，200–6000。
留空时按 Base URL 自动生成；使用工作空间专属域名时可填这里。
仅 Qwen-Audio 模型生效；默认权重 5，写“词语=50”可设为超级热词（最多 50 个）。这是识别偏置，不保证 100% 替换。

建议取消勾选“关闭源时关闭页面”，切换场景后字幕仍会更新；不要勾选“本地文件”。
